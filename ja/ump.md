# UMP（Universal MIDI Packet）とは？

初心者向けに一言で言うと、**UMP は MIDI 2.0 時代の「共通の箱」**です。  
MIDI メッセージを、機器どうしでやり取りしやすい形にそろえるためのパケット形式です。

## 1. まず結論
- UMP = MIDI データを運ぶための標準パケット
- MIDI 1.0 の情報も、MIDI 2.0 の情報も載せられる
- 32-bit（4バイト）単位で構成される

## 2. なぜ UMP が必要？
MIDI 1.0 は長く使われてきましたが、表現力や情報量に限界がありました。  
MIDI 2.0 では高解像度の値や双方向通信が必要になり、**より整理された運び方**が求められます。  
そこで「運搬ルール」を統一したのが UMP です。

## 3. イメージで理解する
- MIDI メッセージ = 手紙の中身
- UMP = 封筒の規格

中身の種類が増えても、封筒の規格が共通なら配達しやすくなります。  
UMP はこの「共通の封筒」の役目です。

## 4. 最初に覚える3つ
1. Message Type  
メッセージの種類。これで「何のデータか」を判別します。

2. Group  
データの通り道を分ける番号です。複数の論理ポートを1本の経路で扱いやすくします。

3. 32-bit ワード構成  
UMP は 32-bit ワードを基本単位にしており、メッセージ種別ごとに  
`32 / 64 / 96 / 128 bit` の長さを使い分けます。

## 5. MIDI 1.0 と MIDI 2.0 の違い（超ざっくり）
- MIDI 1.0: 主に 7-bit 中心の値（例: 0-127）
- MIDI 2.0: より高解像度の値を扱える
- UMP: どちらも同じ運搬ルールで扱える

## 6. よくある誤解
- 誤解: UMP は「新しい音そのもの」の規格  
- 実際: UMP は**データの運び方**の規格（音色規格ではない）
