# MIDI-CI と Profiles

## 1. MIDI-CI の役割
- デバイス間で能力を問い合わせる
- 機能交渉を行い、互換性を高める

## 2. Profiles
- 目的別に振る舞いを標準化する仕組み
- 実装差を減らし、相互運用性を上げる

## 3. Property Exchange
- 構造化データを交換するための仕組み
- 設定・状態の共有に利用される
